# Answerability 标注指南（answerability 数据集 v2 起生效）

> R4.1 建立。R4 评测暴露的 4 FP / 2 FN 中多数是**标注口径分歧**而非系统错误，
> 本指南把"什么叫完整回答"钉死，后续复核与扩数据集都按此执行。

## 1. 判定对象与唯一问题

对每道题只回答一个问题：

> **语料中与问题相关的全部内容，能否让一个只依据语料回答的助手，给出针对本问题完整、明确的答案？**

- 判定对象是**语料内容**，不是检索系统、不是生成模型的表现。
- "相关"不等于"可答"：命中的是答案所在的表 ≠ 表里有答案要求的维度。
- 判定单位是**题**：问题要求 N 项，语料必须覆盖全部 N 项才算可答。

## 2. 四类别的操作定义

### DIRECT（answerable=true）
答案在语料中以**陈述形式**直接出现，无需聚合、无需换算。
例：参数默认值、单一配置项的说明、一条命令的用途。

### TERM_VARIATION（answerable=true）
答案在语料中，但用了同义/别名/缩写。判定者需做**词形对齐**后按 DIRECT 处理。
例：问 maxAge，语料写 maxLifetime 的全称。**注意与 CONFUSABLE 的分界**：
词形对齐后语义完全相同 → TERM_VARIATION；对齐后是**两个不同参数/功能** → CONFUSABLE。

### FOLLOW_UP（answerable=true/false 皆可）
问题含指代（它/这个/因此），语义依赖**会话历史**才能理解。
v2 起样本必须携带 `history` 字段（指代来源的上一轮对话）。
判 answerable 时先解析指代还原完整问题，再按 PARTIAL_EVIDENCE/OUT_OF_KB 规则判。

### CONFUSABLE（answerable=false）
语料与问题高度相似但**不包含答案**：另一产品的同名/近名参数、同一技术的另一功能。
判定关键：对齐后是"不同的东西"，语料数字/结论不能作为本题答案。

### OUT_OF_KB（answerable=false）
语料完全不涉及问题主题。

### PARTIAL_EVIDENCE（answerable=false）—— 口径争议集中区
语料覆盖了问题要求的一部分。**以下规则消除歧义：**

1. **枚举式问题按项计**：问"A/B/C 三种方案各自的优缺点"，语料只讲 A/B → 不可答。
   少一项即不可答，不看"覆盖比例"。
2. **子问题按问计**：一题内含两个问句（如"分别适合什么场景？默认值怎么计算？"），
   任一子问题的答案在语料中**没有陈述**（需要读者推理/补常识）→ 不可答。
3. **"怎么算/为什么"需要规则，不是结果**：语料只给默认值/结论（"默认为两块大小"），
   未给出计算规则或原因链 → "怎么计算"这一问不可答。
   *（R4 seq 63 的裁定：默认值 ≠ 计算规则，维持 answerable=false。）*
4. **聚合要求必须逐项对应**：问"四种原因分别怎么处理"，语料给的是**整体**措施清单
   （未与原因一一对应）→ 若措施与原因的对应关系需要读者自行配对且配对结果不唯一
   → 不可答；若语料明确写了"原因 X → 措施 Y"的对应 → 可答。
   *（R4 seq 56 的裁定：语料是优先级排序的整体措施，对应关系不唯一，维持 false。）*
5. **跨分块聚合**：答案分散在同文档多个分块、且每块都写明对应项 → 可答
   （系统把全部命中喂给模型，跨块聚合是生成端能力，不是证据缺失）。
   *（R4 seq 59 的修订依据：三类错误码各至少 1 条处置散落块内，逐项可对应，改判 true。）*
6. **"依据/原因"问的是语料写明的依据**：语料写"依据是 X"→ 可答；语料只给结论
   没写依据 → 不可答。
   *（R4 seq 60 的裁定：语料明确写了"核心数×2"，依据已陈述，改判 true。）*

## 3. 需要语料之外的推理 → 不可答

- 从"fork 耗时与数据集大小相关"**推理出**"调低快照频率可缓解" → 语料未陈述该缓解
  方案 → 不可答。*（R4 seq 70 的修订依据：参考答案写的是推理出的方案，预期标签偏宽，
  改判 false。）*
- 从参数默认值推理"高并发该怎么调" → 不可答。

## 4. 修订规则（防指标造假）

1. 每处标签修改必须记录：**seq / 原标签 / 新标签 / 修改依据（引用语料原文）**。
2. 修订只允许由**语料原文**驱动；不得因"系统判错了"而反向改标签（那是把评测变成训练）。
3. 同一轮内新增/复核的题目用同一指南判定，禁止双标。
4. 修订后的数据集以**新版本**导入（版本号递增），旧版本保留——R4 与 R4.1 的对照
   必须能回溯到各自版本的样本行。
