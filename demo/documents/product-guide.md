# Aurora Cloud 产品指南

Aurora Cloud 是一个面向企业客户的公有云平台，提供对象存储、托管数据库、容器平台与监控服务四大核心能力。

## 版本

当前稳定版本为 **3.2**。3.1 版本已进入维护期，仅接收安全补丁。

## 核心能力

- **对象存储**：S3 兼容 API，支持生命周期规则与跨区域复制。
- **托管数据库**：提供 MySQL 与 PostgreSQL 托管实例，自动备份，主备高可用。
- **容器平台**：托管 Kubernetes 集群，支持节点池弹性伸缩。
- **监控服务**：指标采集、日志检索与告警通知一体化。

## 部署区域

Aurora Cloud 目前在以下区域提供完整服务：

- cn-north-1（华北一）
- cn-east-2（华东二）
- ap-southeast-1（东南亚一）

各区域的容量与可用性承诺以《区域容量说明》为准。
