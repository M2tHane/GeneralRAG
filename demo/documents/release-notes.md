# Aurora Cloud 版本发布说明

本文件记录 Aurora Cloud 各版本的发布要点，帮助读者区分不同版本引入的功能。

## Aurora Cloud 3.2（当前稳定版本）

发布日期：2026-06-30

- 默认启用跨区域健康检查，区域异常时自动摘除不可用节点。
- 改进数据库连接池监控，连接池指标纳入监控服务默认面板。
- cn-east-2 新增容量扩展，区域可用容量提升至 800。

## Aurora Cloud 3.1

发布日期：2026-02-10

- 新增审计日志导出，支持按天导出操作审计记录。
- 对象存储生命周期规则支持按前缀匹配。

## Aurora Cloud 3.0

发布日期：2025-09-01

- 容器平台正式商用，提供托管 Kubernetes 集群。
- 监控服务新增日志检索能力。

更早版本（2.x）已全部停止维护，此处不再记录。
