# 通用知识问答 RAG — 原型设计记录（prototype/DESIGN.md）

> 本文件是唯一的设计决策记录。维护者：主 Agent（页面代理不直接编辑本文件，决策由主 Agent 汇总）。
> 状态：**第一轮 Stage 2 已完成并获批准（UX APPROVED，2026-09-13）**；**第二轮 Stage 2 进行中**（见 §10 起）。生产实现须保留本文信息层级与交互语义。

## 0. 任务定义（一句话）

当团队成员需要让 AI 依据团队技术文档与故障手册回答问题时，需要把文档可靠地入库、检索并生成带来源引用的回答，以便获得可追溯、可验证的答案。

## 1. 信息架构与导航

- 应用外壳：左侧浅冷灰侧栏（232px，窄屏收起为抽屉）+ 56px 顶栏 + 白色主工作区。
- 顶层导航 3 项：**知识库**（kb.html，含文档管理）、**知识问答**（chat.html）、**检索调试**（debug.html）。文档详情（doc-detail.html）为知识库域的二级页，不进顶层导航。
- ~~评测无第一版页面，导航中不放置任何评测入口。~~ **【第二轮变更】** 第二轮解除此限制：顶层导航新增第 4 项 **效果评测**（eval.html），与「知识库 / 知识问答 / 检索调试」并列。依据见 §10。
- 顶栏放当前知识库上下文（问答/调试页需要先选库），不放全局搜索。

## 2. 页面类型与主操作

| 页面 | 文件 | 主类型 | 唯一主操作 | 容器决策 |
| --- | --- | --- | --- | --- |
| 知识库列表 | kb.html | Object List | 新建知识库（Modal，≤5 字段） | 删除确认用 Modal，明确影响范围 |
| 文档管理 | docs.html?kb=… | Object List（含处理队列特征） | 上传文档（Modal：选择文件+分块策略） | 删除确认 Modal；失败原因行内可见 |
| 文档详情 | doc-detail.html?doc=… | Object Detail（平级 Tabs） | 无（重试/删除在头部操作区） | 独立页面：解析文本/分块预览内容长，需稳定 URL；顶部返回路径 |
| 知识问答 | chat.html | Master–Detail（会话列表+对话区） | 发送提问 | 会话管理用轻量菜单；引用分块从侧栏 Drawer 预览 + 可跳转文档详情 |
| 检索调试 | debug.html | Investigation | 执行检索调试 | 上下文/命中详情用可展开区块，保持一屏证据链 |

## 3. 首屏与内容去向

- **kb.html**：知识库表格（名称、描述、文档数、分块数、更新时间、操作）。空库/筛选无结果状态由模拟开关控制。
- **docs.html**：标题=知识库名；工具栏=状态筛选（全部/处理中/已完成/失败）+ 上传按钮；表格列=文档名、格式、状态+阶段、分块数、大小、上传时间、操作（详情、More：重试/删除）。失败原因显示在失败行内（错误图标+文案，不靠小字）。
- **doc-detail.html**：头部=文档名+状态+操作（重试/删除）；Tabs：解析文本 / 分块预览 / 基本信息。分块预览为表格（序号、标题路径、页码、字符数、内容摘要）带分页。
- **chat.html**：左 260px 会话列表（新建/切换/删除），右侧对话区。助手回答下方为来源引用条（点击展开分块原文）。SSE 阶段以紧凑阶段行呈现，无虚假百分比。流式异常（超时/中断/取消）有重试与输入保留。
- **debug.html**：顶部查询输入+检索参数（生效配置只读展示）+ 执行按钮；下方命中列表（排名、分数、文档、分块、标题路径）；右侧/下方=各阶段耗时、实际送入模型的上下文。资料外问题演示"未召回"。

## 4. 关键交互语义

- 上传后立即出现"排队中"行并异步推进阶段（模拟 setTimeout 推进），体现"接口不等待流程"。
- 重复上传同名且同内容哈希的文件 → 明确提示"知识库内已存在相同文件"。
- 删除知识库/文档 → 确认 Modal 列出影响范围（将清除分块、向量、会话引用）。
- 回答引用只来自本次检索命中；资料不足时回复"无法依据当前资料回答"，不伪造引用。
- 调试页与问答页使用同一份检索模拟数据，保证两边一致。

## 5. 状态覆盖（演示控制位于侧栏底部工具区，默认收起）

各页提供：loading（骨架屏）、empty（真正为空）、filtered-empty、error（含重试）、提交中/失败输入保留、长文本。主题 Light/Dark/System 由侧栏底部分段控件控制，localStorage 持久化。

## 6. 字号与文案约束

- 页面标题 22px/加粗；Section 标题 16–18px；正文/表格/Label ≥14px；元数据 13px。
- 中文界面，无英文眉题/装饰性副标题；技术名词（PDF、SSE、Hit@K）保留。
- 辅助文案只保留范围、约束、后果、恢复信息（如"扫描件 PDF 暂不支持"）。

## 7. 原型边界声明

- 全部数据为 `prototype/data.js` 内模拟数据，无真实后端；页面间通过 URL 参数（kb、doc、chunk）传递上下文，修改仅存于当前页面内存。
- 演示控制区在侧栏底部工具区内，默认收起，不遮挡业务控件。

## 8. 页面代理决策（已汇总）

- **kb.html**（Object List）：主操作「新建知识库」；新建/重命名居中 Modal（2 字段）；删除确认 Modal 列影响范围（N 篇文档、分块与向量清除、会话引用失效），空库提示更轻；重命名/删除为行内动作。
- **docs.html**（Object List，处理队列特征）：主操作「上传文档」，Modal 内模拟文件选择（MD/TXT/文本型 PDF/扫描件 PDF）+ 分块策略单选；上传三分支 = 哈希去重提示 / 扫描件不支持 / 新增排队行；异步推进 排队→解析→清洗→分块→向量化→入库→已完成（1.5–2.5s/步）；失败原因行内正常字号展示；重试/删除收 More 菜单；状态筛选分段控件；分页 10/20、>7 页跳页校验、删除收敛页码；演示开关：立即完成、注入批量文档（76 条）、loading/empty/error。
- **doc-detail.html**（Object Detail，平级 Tabs）：解析文本 / 分块预览 / 基本信息；失败文档主操作=重试（逐阶段推进，已完成阶段快速带过）；删除在 More 菜单+确认 Modal；分块表点击行就地展开（不用 Drawer，无背景参考需求）；&chunk= 自动切 Tab 定位高亮 2.2s；基本信息用定义列表不套 Card；演示开关：长内容样例、重放 loading。
- **chat.html**（Master–Detail）：主操作=发送（Ctrl/Cmd+Enter）；会话列表新建/切换/删除（删除 Modal 确认）；知识库选择器过滤会话；SSE 阶段行复用 .stage-line（检索命中 N 块 · Xms → 生成中），打字机 150ms/步（reduced-motion 一次性完成）；资料外问题回复「无法依据当前资料回答」+相似度低于阈值说明，零伪造引用；引用条点开 Drawer 看分块原文并「查看完整文档」跳 doc-detail；异常全覆盖：防重复提交、停止（保留已生成+「已手动停止」）、模型超时、SSE 流中断、检索失败，全部保留输入可重试；窄屏会话列表收为抽屉；演示开关 5 项+重置数据。
- **debug.html**（Investigation）：主操作=执行检索调试；生效配置只读带；证据顺序=问题线索警示 → 命中表（排名/分数/文档/标题路径/页码/已过滤标记）→ 耗时+模型上下文并排；演示开关支持调 topK/minScore 实时重算过滤与线索文案，minScore 调高演示全部过滤→filtered-empty；与问答页同一份模拟数据（引用一致性经脚本断言）；URL ?kb=&q= 预填执行。

# 【第二轮】检索与效果优化 — 设计决策（Stage 2，进行中）

> 依据：`docs/round2/01-需求理解.md`（已批准；默认取值 Q1–Q4 与完整 MVP 范围）。
> 第二轮新增 UI：**效果评测**（eval.html / eval-run.html）、**检索调试阶段位次**（debug.html 扩展）、**拒答引用语义**（chat.html + debug.html）。

## 10. 第二轮信息架构与导航

- 顶层导航由 3 项扩为 **4 项**：知识库 / 知识问答 / 检索调试 / **效果评测**（eval.html）。理由：第一轮「导航不放评测入口」的前提是「评测无页面」；本轮评测是主要交付能力，入口必须可达（R2-C1）。
- 页面类型（第二轮新增）：

| 页面 | 文件 | 主类型 | 唯一主操作 | 容器决策 |
| --- | --- | --- | --- | --- |
| 效果评测（运行列表） | eval.html | Object List | 发起评测运行（Modal，≤4 字段） | 运行详情走独立页（指标+配置+逐题表，内容长且需稳定 URL） |
| 运行详情 / 对比 | eval-run.html | Object Detail + Comparison | 两次运行对比（选择基线/实验） | 单页承载单次与两次两种模式，由 URL 参数决定；逐题下钻就地展开 |

- **页面数决策（用户已确认）**：评测 UI 采用 **2 页**——列表 + 详情/对比合一。单次运行与两次对比共享指标栏、配置快照与逐题表组件，不拆第三个对比页，避免重复实现与多余跳转。
- **运行详情与对比的切换方式**：页面用 `?run=<id>` 看单次；`?base=<id>&exp=<id>` 看两次对比；页头提供「与另一次运行对比」入口（选第二次运行），对比模式下可「退出对比」回单次。两种模式共用同一 URL 路径。

## 11. 第二轮页面结构

- **eval.html（运行列表）**：工具栏=数据集筛选 + 知识库筛选 + 发起运行；表格列=运行时间、数据集（名+版本+锚点模式）、检索模式、Hit@1/3/5、Recall@5、MRR、拒答正确率、p95 耗时、状态、操作。多选 2 项显示「对比选中运行」。失败运行行内显示失败原因；运行中显示阶段。分页 10/20、多页跳页（沿用第一轮规范，分页停靠工作区底部 24–32px）。
- **eval-run.html（运行详情/对比）**：
  - 单次模式顺序：指标栏（Hit@1/3/5、Recall@5、MRR、拒答正确率、p50/p95/max）→ 排名分布 → 配置快照（检索模式、各通道 topK、RRF k、是否重排+模型+是否降级、minScore、embedding 模型/维度、分块策略、语料分块数）→ 逐题表（问题、类别、可达性、命中、排名、耗时、归因、标注），行可展开看两轮回答/引用/分阶段排名。
  - 两次模式顺序：**可比性守卫带**（comparable / 不可比差异字段列表 / 配置无差异提示）→ 指标变化栏（每指标基线值、实验值、delta）→ **逐题计数**（N 题变好 / N 题变差 / N 题不变）→ 逐题对比表（默认按「最严重退化」排序）→ **归因汇总**（7 类计数 + 筛选 + 标记已处理）。
- **debug.html 扩展（用户已确认）**：主表保留一屏证据链（最终排名、文档、标题路径、页码、最终分数、是否通过阈值）；**行可展开显示该候选的向量/BM25/融合/重排各阶段位次与分数**（`.stage-ranks`）。顶部增加通道开关（混合/重排）与**降级提示带**（重排失败时）。标题路径展示修复前后对照。
- **chat.html 拒答语义（R2-A1）**：资料不足时回答为「当前资料不足以回答该问题。」且**引用区为空**；低相关命中仅在检索调试页可见。契约与文案一致，不出现「拒答却挂来源」。

## 12. 第二轮关键交互语义

- 评测列表与详情读的是模拟 `MockData.evalRuns` / `evalRunItems`；对比为客户端按 `seq` 关联（不新增端点，见需求 §7.9）。
- **可比性守卫**：数据集版本不匹配（v1 文档级 vs v2 分块级）判为不可比并列出差异字段；配置完全相同的两次运行提示「配置无差异」，避免把 0.00 delta 误读为「无提升」。
- **重排降级**必须可见：降级运行的配置快照与对比表均标注「已降级、未重排」，不把降级结果与正常重排结果混为可比结论。
- 归因汇总需支持**筛选**与**标记已处理**（就地改变原型数据），不只逐题打标。
- 指标一律带定义（`runMetricMeta`），比率显示为百分比、耗时显示 ms；`null` 指标显示 `—`，不显示 0。
- 运行中/失败的运行不显示指标为 0 或空表格，显示明确状态。

## 13. 第二轮状态覆盖

- eval.html：loading 骨架、empty（无运行）、filtered-empty（筛选无结果）、error（加载失败可重试）、运行中、失败运行（行内原因）。多选对比的边界：选 1 项、选 3 项、选到不同数据集版本。
- eval-run.html：单次运行中（部分逐题）、失败运行（失败原因 + 无指标）、不可比组合（守卫带）、配置无差异、逐题筛选无结果、归因「全部已处理」。
- debug.html：重排降级、通道开关关闭（仅向量）、无候选通过阈值、titlePath 修复前后对照。
- chat.html：拒答（空引用 + 明确文案）、正常回答（引用非空）。

## 14. 第二轮字号与文案约束

沿用 §6：正文/表格/Label ≥14px，元数据 ≥13px；中文界面无英文眉题/装饰性副标题；技术名词（Hit@K、Recall@K、MRR、RRF、BM25、p95）保留。新增约束：

- 指标名保留英文缩写，但必须带中文释义（悬浮或就地小字，`runMetricMeta.desc`），不假设用户知道 MRR/Recall@K 含义。
- 归因类型使用中文标签（未召回/排名下降/被阈值卡掉/上下文截断/分块边界切断/拒答误判/生成错误），不直接显示枚举常量。
- 「已降级、未重排」属会改变结论理解的约束信息，必须正常字号展示，不得改为更淡更小。

## 15. 原型边界（第二轮补充）
